# INTRODUCTION

W3C PNG version 3 adds "APNG" chunks to the PNG definition to support animated PNG files.

The APNG reading, editing and authoring toolkit, **AREATK**, includes a library **libapng** that provides extra functionality to stock [libpng](http://libpng.org/pub/png/libpng.html]) for the reading and writing of the APNG extensions to PNG.

The full documentation of the new chunks is to be found on the W3C web site [Portable Network Graphics (PNG) Specification (Third Edition)](https://www.w3.org/TR/png-3/).

The specification is currently a candidate recommendation draft (CR) intended to replace the [Portable Network Graphics (PNG) Specification (Second Edition)](https://www.w3.org/TR/2003/REC-PNG-20031110/).
